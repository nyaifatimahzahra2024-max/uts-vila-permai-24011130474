## Deskripsi Fitur
Website ini merupakan aplikasi web pemesanan vila sederhana yang dikembangkan untuk Ujian Tengah Semester (UTS). Fitur-fitur yang tersedia meliputi:
1. Struktur HTML semantik.
2. Desain CSS responsif dengan penataan tata letak antarmuka.
3. Logika JavaScript untuk pengelolaan data, pencarian, interaksi, serta penyimpanan data menggunakan `localStorage`.

## Cara Menjalankan Halaman

1. Buka folder project menggunakan teks editor (seperti VS Code).
2. Buka file `index.html` langsung di browser atau gunakan ekstensi *Live Server*.
